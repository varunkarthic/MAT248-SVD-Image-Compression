See how linear algebra rebuilds an image, one singular component at a time.

An image is a matrix. The singular value decomposition splits that matrix into ranked layers, and keeping only the strongest layers gives the best possible lower-rank picture. Everything below is computed by a singular value decomposition written from scratch for this project.
