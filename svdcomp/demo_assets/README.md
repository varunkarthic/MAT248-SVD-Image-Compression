# Demonstration images

Nine bundled images used by the SVD LAB gallery. They work offline.

| File | Source |
| --- | --- |
| `gradient`, `checkerboard`, `shapes`, `edges`, `low-rank`, `texture`, `tiny-face` | Generated by closed-form formulas or a fixed random seed in `svdcomp/samples.py` |
| `photo-gray`, `photo-color` | NASA portrait of astronaut Eileen Collins (public domain), 256 x 256, from `docs/_static/figures/astronaut.png` |

Regenerate everything with `python -m svdcomp.samples` (needs the repository checkout for the photograph).
`manifest.json` lists each image's title, description and the reason it is interesting for the SVD.
