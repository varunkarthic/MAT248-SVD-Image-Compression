Image compression with the Singular Value Decomposition: a simple guide for MAT248

1. An image is a matrix

A grey picture is a grid of tiny squares (pixels). Each pixel has a brightness from 0 (black) to 255 (white). Write those brightness numbers in rows and columns and you have a matrix A with m rows and n columns. A colour picture is three such matrices: red, green and blue. We treat each one separately.

2. The tools we need

  • Matrix multiplication: entry (i, j) of AB = (row i of A) · (column j of B). Example: row (3, 1) times column (1, 1) = 3·1 + 1·1 = 4.
  • Vector: a list of numbers, e.g. a column of the matrix.
  • Transpose AT: swap rows and columns.
  • Rank: the number of independent rows (or columns). If one row is just a multiple of another it adds no new information. Rank 1 means "one pattern repeated".
  • Eigenvector: a direction that a matrix only stretches: Av = λv. The stretch factor λ is the eigenvalue.

3. The Singular Value Decomposition (SVD)

Every matrix can be written as

A = U Σ VT
  • U and V: matrices whose columns are perpendicular unit vectors (rotations/reflections). Their columns are u1, u2, … and v1, v2, …
  • Σ: a diagonal matrix of singular values σ1 ≥ σ2 ≥ … ≥ 0. They say how important each pattern is.
  • The σi are the square roots of the eigenvalues of ATA; the vi are its eigenvectors; ui = A vi / σi.

The same thing as a sum of simple layers (each layer is a rank-1 matrix):

A = σ1u1v1T + σ2u2v2T + σ3u3v3T + …

5. Why this compresses an image

Keep only the first k layers: Ak = σ1u1v1T + … + σkukvkT. Because the σ's are sorted, the layers we keep are the most important ones. More layers means more detail.

Eckart–Young–Mirsky theorem: among all matrices of rank at most k, Ak is the closest to A (in the Frobenius norm and the 2-norm). The error is ‖A − Ak‖F² = σk+1² + σk+2² + …
  • Energy kept: E(k) = (σ1² + … + σk²) / (σ1² + σ2² + …).
  • Numbers to store: k(m + n + 1) per colour channel, instead of m·n. For 256 × 256 and k = 20 that is 10 260 instead of 65 536.
  • Quality: MSE (average squared error), PSNR = 10 log10(255² / MSE) in dB (higher is better), SSIM (closer to 1 is better).

6. What the demo shows

  1. Choose a sample image (or upload your own) and press Compute SVD. Exact = full Jacobi SVD; Randomized = a faster approximation of the leading layers.
  2. Press Play: each picture is a real rank-k reconstruction, from rank 1 upwards. The rank, charts, energy and error all change together.
  3. Drag the divider to compare with the original; type any rank; open Show component to see one layer σiuiviT (blue = negative, red = positive).
  4. Try Checkerboard (rank 2: two layers are enough) versus Complex texture (many layers needed).
  5. Adaptive blocks: the image is cut into tiles; detailed tiles get more rank.

7. Honest limits

  • k(m+n+1) is a count of numbers, not a file size. A reconstruction saved as PNG is just an image.
  • JPEG and WebP usually give smaller files than plain SVD.
  • Randomized SVD is an approximation; it is not guaranteed to equal the best rank-k matrix.
  • Error before rounding to 8-bit pixels (exact mathematics) is slightly different from error measured on the final picture.

8. Likely questions

Why σ = √(eigenvalue of AᵀA)?

Because AᵀA = V Σ² Vᵀ, so its eigenvalues are σ².

Why are the singular values sorted?

So that keeping the first k layers keeps the biggest ones, which minimises the error (Eckart–Young).

Is the SVD unique?

The singular values are; the vectors are unique only up to sign (and rotation if values repeat).

Why do colour images need three SVDs?

R, G and B are three separate matrices; we decompose each.

Why can randomized SVD be faster?

It compresses A with a random matrix first, then does an SVD of a small matrix: roughly O(mnk) work.
